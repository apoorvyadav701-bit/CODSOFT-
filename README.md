# CODSOFT-
Advanced and user-friendly Todo Application built using Python, CustomTkinter, and SQLite. This project provides a modern graphical interface for managing daily tasks efficiently. Users can add, update, delete, and organize tasks with a smooth and responsive GUI. 
Ultimate Todo App

A modern and advanced Todo Application built using Python, CustomTkinter, and SQLite.

Features

- Add New Tasks
- Delete Tasks
- Mark Tasks as Completed
- Calendar Integration
- Dark Mode GUI
- SQLite Database Storage
- User-Friendly Interface

Technologies Used

- Python
- CustomTkinter
- SQLite3
- TkCalendar

Installation

pip install customtkinter tkcalendar

Run the Project

python main.py

Project Purpose

This project was created to practice Python GUI development and database management while building a real-world productivity application.
